# Publication contents

The repository contains game source, original assets, license notices,
documentation, native test/build tools, and a Linux CI workflow.

Release packages use an explicit install-file list. Source packages are exported
from tracked Git files without `.git` metadata. Build scratch files, compiler
request/response dumps, local SDK installations, handoff notes, machine paths,
credentials, calculator ROMs and personal saves are excluded. Original public
upstream attribution and history remain intact.

The repository can remain private while preparing a release. Changing its
visibility is a separate publication step. Review subsequently added files and
release assets before changing visibility; ignore rules do not scrub previous
commits or assets.
